?? AMD BC-250 Pacman Repository

Official pre-compiled rolling-release package repository for the AMD BC-250 (Sony PS5 Oberon APU) running CachyOS Linux.

1. Add to /etc/pacman.conf (Works on Fish, Bash & Zsh):

printf "
[bc250-cockpit]
SigLevel = Optional TrustAll
Server = https://snk-b.github.io/bc250-packages/\$arch
" | sudo tee -a /etc/pacman.conf

2. Install:

sudo pacman -Sy --overwrite "*" bc250-cockpit-pro

x86_64 CachyOS Linux v1.1.1-2
